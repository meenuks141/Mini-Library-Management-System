# Mini Library Management System
A command-line library management application built using Python
for the LF 2026 challenge.

## Features

- Add new books
- Display all books
- Search for books
- Borrow books
- Return books
- Detect overdue books
- View borrowing history
- Generate a library summary
- Save records to text files

## Technologies Used

- Python
- Lists and dictionaries
- Functions
- Conditional statements
- Loops
- File handling
- datetime module

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:
   python3 main.py
   
## Data Storage

- books.txt stores book information.
- borrowing_records.txt stores borrowing history.
